# G-HEP 웹사이트 운영 안내 · V2

가천대학교 보건경제정책연구소(G-HEP) 사이트 V2입니다. GitHub Pages용 정적 웹사이트로, 연구분야 상세 페이지, 2026년 9월 월간 보건경제 동향 리포트 예시, 홍지형·안소윤·이성현의 2022–2026년 선정 논문 목록과 2025년 이후 학술지별 연구동향을 포함합니다. 연구소 소개, 장소, 연락처는 제공받은 문구와 주소를 반영했습니다. 9월 리포트 원고의 대외 발행 여부는 아직 확정하지 않았습니다.

## 사이트맵

| 상위 메뉴 | 하위 구성 |
| --- | --- |
| 연구소 소개 | 소개, 연구분야, 주요 연구실적(연도별 논문 목록), 장소 및 대표 연락처 |
| 주요국 경제성평가 지침 | 국내 HIRA, England NICE, Australia PBAC, Canada CDA, United States ICER, 국제 방법론 ISPOR |
| 연구동향 | 국내/해외, 학술지별 보기, 출판일 순 전체 목록, 제목·저자·키워드 검색, 논문 상세(저자·출판일·초록 요약·DOI) |
| 이슈브리프 | 월간 보건경제 동향 리포트와 주제별 이슈브리프. 신약·희귀의약품 급여평가, 지침 개정, 위험분담제, 평가 방법론 |

ISPOR는 국가별 지침이 아닌 국제 학회의 방법론 자료로 분류했습니다. ICER는 미국의 독립 비영리 평가기관입니다.

## GitHub Pages에 올리기

1. ZIP을 풀고 그 안의 `index.html`, `research-fields.html`, `research-achievements.html`, `reports` 폴더, `assets` 폴더, `content` 폴더, 자동 수집을 이용한다면 `.github` 폴더와 `scripts` 폴더를 저장소의 **최상위 위치**에 올립니다. 이 README는 이미 저장소에 README가 있다면 내용을 합쳐서 사용하세요.
2. 저장소에서 **Settings → Pages → Build and deployment**로 이동합니다.
3. **Deploy from a branch**를 선택하고 `main`, `/(root)`를 지정한 뒤 **Save**를 누릅니다.
4. 배포가 끝나면 같은 화면의 **Visit site**에서 주소를 확인합니다. 이 저장소가 `yifromseoul-ai/G-HEP`라면 일반적인 프로젝트 사이트 주소는 `https://yifromseoul-ai.github.io/G-HEP/`입니다.

`index.html` 하나만 올리면 화면의 스타일·동작·논문 목록·월간 리포트가 빠집니다. 이번 시안은 폴더 구조 전체를 올려야 합니다. 첫 화면을 `file://`로 직접 실행하면 브라우저가 JSON을 읽지 못할 수 있으므로, GitHub Pages 또는 로컬 웹 서버에서 확인하세요. 세 상세 HTML 문서는 단독으로 열어도 읽을 수 있습니다.

## 게시글을 추가하는 방법

`content/trends.json`의 배열에 논문 객체를 하나 추가합니다. `published`는 확인 가능한 범위에서 `YYYY-MM-DD` 또는 `YYYY-MM`으로 적습니다. 화면은 출판일을 기준으로 정렬합니다. 원문에서 확인되지 않은 저자·날짜·DOI는 채우지 마세요. `abstract_summary`에는 원문 초록을 복사하지 않고, 핵심을 요약한 문장을 넣습니다.

```json
{
  "id": "unique-article-id",
  "title": "확인된 논문 제목",
  "journal": "Value in Health",
  "scope": "international",
  "published": "2026-07-14",
  "authors": "원문에서 확인한 저자",
  "abstract_summary": "원문 초록의 짧은 요약",
  "doi": "10.xxxx/확인된-DOI",
  "source_url": "https://원문-주소"
}
```

`scope`는 `domestic` 또는 `international`을 사용합니다. `journal`은 화면의 학술지 명칭과 정확히 같아야 학술지별 필터에 표시됩니다. 새 글을 추가할 때 배열의 기존 마지막 항목 뒤에 쉼표를 넣고 새 객체를 추가하세요. JSON 문법 오류가 있으면 목록 전체가 로드되지 않습니다.

`content/briefs.json`에 브리프 객체를 추가하면 발행 목록과 상세 화면에 자동으로 나타납니다. 날짜는 `YYYY-MM`, 근거 링크는 `https://` 주소를 사용합니다.

```json
{
  "id": "2026-10-topic-slug",
  "month": "2026-10",
  "category": "급여평가",
  "title": "확인된 이슈의 제목",
  "summary": "이슈의 핵심을 두세 문장으로 정리",
  "sections": [
    {"heading": "배경", "body": "원문 확인 후 작성한 내용"},
    {"heading": "평가와 시사점", "body": "근거와 해석을 구분한 내용"}
  ],
  "sources": [
    {"label": "기관 원문 및 확인일", "url": "https://기관-원문-주소"}
  ]
}
```

## 월간 리포트와 연구실적 갱신

- 월간 리포트는 `reports/2026-09.html`을 복사해 새 파일명(예: `2026-10.html`)으로 저장하고, 제목·기간·발행일·본문·원문 출처를 갱신합니다. `index.html`의 `.report-list-card`를 복사해 발행 목록에 새 링크를 추가합니다. 현재 9월호는 게시 형식 검토용 예시입니다. 국내 동향, 국제 동향, 출처·편집 기준의 세 부분으로 구성하며, ‘이번 달의 관점’과 ‘다음 달 확인할 사항’은 포함하지 않습니다. 기관 명의 공개 전 내용과 발행 여부를 검토하세요.
- 결정의 날짜와 단계(허가, 심의, 권고, 실제 급여 적용)를 정확히 적습니다. 출처는 기관의 원문 URL을 넣고, 기관 발표 사실과 연구소의 해석을 별도 단락으로 나눕니다. 9월호는 제공받은 MFDS 자료의 **월호별 독립 게시글·원문 링크 방식만** 참고하고 기사·디자인은 새로 작성했습니다.
- 연구실적은 `research-achievements.html`의 연도별 `<section class="year">`에서 한 논문의 `<li>` 블록을 복사해 추가합니다. 저자 전원, 원문 제목, 학술지, 권·호·쪽수, DOI를 발행사 또는 KCI 서지와 대조하고, 함께 쓴 논문은 한 번만 게시합니다. 홍지형·안소윤·이성현의 이름은 저자란에서 굵게 표시합니다. 논문 앞 일련번호는 자동으로 매겨집니다. SCI(E), KCI, SSCI 배지는 발행사 학술지 색인 정보가 바뀔 수 있으므로 갱신 시 재확인합니다.
- `research-achievements.html` 본문은 SCI(E)·SSCI·KCI 논문을 연도별로 통합해 표시합니다. 연도별 편수는 표시하지 않아 새 논문을 추가해도 제목을 수정할 필요가 없습니다. 2026년 10월 20일 현재 공개된 자료로 정리했으며, 같은 이름의 다른 기관 연구자 논문은 제외했습니다. 공저 참여만으로 연구소 주도 성과로 보기는 어려운 ‘고가 의약품 건강보험 급여 현황 분석’은 이 선정 목록에서 제외했습니다. KCI 서지에 DOI가 없는 세 편은 식별자를 추측하지 않았습니다.

## 연구동향의 주간 업데이트

V2의 수록 목표는 국내외 지정 학술지 8종에서 2025년 이후 발표된 정규 논문 전체입니다. 주제와 상관없이 수록하되, 학회 초록집·포스터 초록·정오표·철회 고지 등은 제외합니다. 출판일은 확인된 서지 범위 그대로 `YYYY-MM-DD` 또는 `YYYY-MM`으로 표시합니다. 2026년 10월 20일 기준 공개 출처에서 모은 서지 후보는 총 3,090건입니다. 세부 수와 확인한 권호는 `content/trends-coverage.json`에 있습니다. 국제 2,828건 중 Crossref만 등록된 42건(그중 *Social Science & Medicine* 온라인 선공개 41건)은 PubMed 논문 유형 확인 전이어서 화면에도 검토 중이라고 표시합니다. 공개 목차와 서지 서비스의 갱신 시차 및 분류 오류가 있을 수 있으므로, 이 건수를 해당 학술지 전체 발행 건수로 단정하지 마세요.

V2 ZIP에는 최초 서지 후보 3,090건이 미리 들어 있으며, ZIP 전체를 게시하면 이 후보 목록이 바로 보입니다. `.github/workflows/update-trends.yml`은 그 후 매주 월요일 10:17(KST)에 `scripts/sync_trends.py`를 실행합니다. 수집기는 공개 학술지 목차·논문 페이지와 PubMed·Crossref 등 접근 가능한 서지 경로를 사용하며 KCI 인증키가 필요하지 않습니다. 실제 서지나 출처 집계가 달라지면 검토용 풀 리퀘스트(PR)를 만듭니다. 날짜만 달라진 경우에는 파일을 다시 쓰지 않습니다. 담당자가 새 자료의 정규 논문 여부와 서지·출처를 확인하고 병합하면 GitHub Pages에 반영됩니다. `content/trends.json`의 기존 검토 원고는 별도로 유지되고 동일 DOI가 있으면 검토 원고가 우선합니다. 저장소의 Actions 권한에서 쓰기와 PR 생성이 허용되어야 PR이 만들어집니다.

자동 수집은 서지정보를 모으는 단계입니다. 3,090건의 초록 요약이 모두 작성되었다는 뜻이 아닙니다. 공개 서지에 초록이 있는 항목에는 원문 초록 링크를 제공하며, 요약은 검토가 끝난 항목에만 `content/trends.json`을 통해 추가합니다. 원문을 확인하지 않고 내용을 추측하거나 초록 전문을 복사하지 않습니다. 담당자는 PR에서 제목·저자·출판일·DOI·원문 링크를 대조하고, 필요하면 초록을 읽어 별도로 짧게 요약합니다. 특히 *Value in Health*의 학회 초록 부록과 온라인 선공개·정규 권호 간 중복, Crossref만 등록된 42건의 논문 유형을 점검하세요. 공개 출처에 빠진 기록은 각 학술지의 권·호 목차와 대조하여 수동 보완합니다. PR을 병합하지 않으면 자동 생성된 변경 사항은 사이트에 게시되지 않습니다.

## 디자인과 자료 출처

- 가천대학교 로고는 [가천대학교 공식 로고 페이지](https://www.gachon.ac.kr/pr/1459/subview.do)의 원본 이미지를 사이트에서 직접 참조합니다. 현재 파일 안에 이미지를 복사해 포함하지 않았으므로 대학 서버 접근 상태에 따라 표시가 달라질 수 있습니다. 지속 운영 시 공식 원본을 저장소 `assets/`에 보관하고 `index.html`의 `src`를 해당 파일로 바꾸는 것을 권장합니다.
- 색상은 가천대학교 공식 UI의 코발트 블루와 보조 색감에서 참고했습니다. 이 시안의 수치를 대학 웹의 의무 규격이라고 뜻하지는 않습니다.
- 경제성평가 지침 카드에는 각 평가기관·단체의 원문 링크가 들어 있습니다. 특히 CDA 카드의 제4판은 2017년 발행본이며, 기관별 개정 현황은 발행 시점마다 확인해야 합니다.
- `content/trends.json`의 기존 검토 논문 네 건에는 출처와 짧은 초록 요약이 있습니다. 자동 수집된 항목은 검토 단계에 따라 서지정보만 제공할 수 있습니다.
- 연구소 위치는 [가천대학교 오시는 길](https://www.gachon.ac.kr/mana/3261/subview.do)에서 주소와 가천관을 대조했습니다. 지도는 OpenStreetMap의 삽입 지도를 사용하며, 지도가 차단될 때를 위해 주소와 별도 링크를 함께 제공합니다.
